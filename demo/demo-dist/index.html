Install Design Workbench

一个安装入口，三个官方宿主

Elens 现在按 Web、Extension、Desktop 三个入口组织。统一保留同一份 inspector core，再按宿主差异装配 viewport、clipboard 和 capture 能力。

打开安装入口 打开 Design Workbench
正在加载当前 Demo 宿主状态…
Web

SDK 挂载入口

适合站点、内嵌 demo 或调试页面，直接通过 `./web` 暴露的 `mountElementInspector` 挂载。

import { mountElementInspector } from 'elens/web'

mountElementInspector({ enabled: true })
  • 复用默认 inspector core
  • 可选接入宿主 viewport controller
  • 当前 demo 已改为走这个入口
Extension

浏览器扩展入口

适合 Chrome extension content script。通过 `./extension` 获取 bridge controller 和薄装配入口。

import {
  createChromeExtensionViewportController,
  mountChromeExtensionInspector,
} from 'elens/extension'
  • 把窗口控制、截图、剪贴板能力放在 adapter 层
  • content script 入口只负责 toggle 和消息转发
  • 保留现有 extension build 流程
Desktop

桌面宿主骨架

适合 Electron / Tauri。先通过 `./desktop` 暴露 desktop controller stub，验证宿主接口装配方式。

import {
  createDesktopViewportController,
  mountElementInspector,
} from 'elens/desktop'
  • 这轮是可接入骨架，不是完整 Electron 产品壳
  • 可逐步补 window bounds、capture、clipboard 桥接
  • 不影响已有 web / extension 使用方式
